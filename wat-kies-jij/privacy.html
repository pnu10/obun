Privacybeleid

Ingangsdatum: 22 september 2026

"Wat Kies Jij" (hierna: de tool) is een interne tool waarmee de beheerder van het YouTube-kanaal What If? zelfgemaakte video's uploadt naar het eigen kanaal.

1. Gebruikte rechten

Via Google-accountverificatie vraagt de tool alleen toestemming om video's naar YouTube te uploaden (youtube.upload). Deze toestemming wordt uitsluitend gebruikt om video's naar het eigen kanaal te uploaden.

2. Verzamelde gegevens

De tool verzamelt geen persoonsgegevens van andere gebruikers. Het toegangstoken wordt alleen op de computer van de beheerder bewaard en wordt niet verstuurd naar of gedeeld met derden.

3. Google-gebruikersgegevensbeleid

Het gebruik van informatie die via Google API's wordt ontvangen, voldoet aan het Google API Services User Data Policy, inclusief de vereisten voor beperkt gebruik (Limited Use).

4. Toestemming intrekken

Je kunt de toegang van deze tool op elk moment intrekken via myaccount.google.com/permissions.

Privacy Policy (English)

Wat Kies Jij is an internal tool that uploads videos we produce to the operator's own YouTube channel (What If?). It requests only the YouTube upload scope (youtube.upload). It does not collect personal data from other users. OAuth tokens are stored only on the operator's computer and are never shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: ifwhat319@gmail.com
